## Layout & Responsiveness

The main focus of this project was learning how to combine **CSS Grid and Flexbox** to create a complete dashboard layout.

**CSS Grid** is used for the overall structure of the page. The dashboard is divided into columns and rows to organize the sidebar, headers, projects section, announcements, and trending section.

**Flexbox** is used within individual sections to control alignment and positioning. It is used for elements such as the sidebar navigation, header content, profile information, buttons, announcements, and trending items.

The project cards use a flexible Grid layout with `auto-fill` and `minmax()`, allowing the number of columns to adjust based on the available screen width. This helps the dashboard adapt to different laptop and desktop monitor sizes without relying on a fixed number of project columns.

The layout is designed to work responsively across different **laptop and desktop screen sizes**. It is **not specifically customized or optimized for mobile phone screens**.

## Features

- Project card layout

- Trending section
- Responsive project grid for different screen widths

- Using Flexbox for alignment and positioning

- Using `auto-fill` and `minmax()` to create flexible Grid layouts

- Building a dashboard that adapts to different laptop and desktop screen sizes
